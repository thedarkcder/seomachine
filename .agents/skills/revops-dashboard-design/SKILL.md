# Dashboard Design

Use this skill when leadership or operators need clear visibility into sales, marketing, SDR, or revenue performance.

## Workflow

1. Define audience:
   - executive team
   - marketing lead
   - SDR manager
   - sales leader
   - RevOps owner
   - customer success leader

2. Select dashboard type:
   - executive revenue snapshot
   - marketing source and campaign performance
   - SDR activity and conversion
   - pipeline health
   - lifecycle funnel
   - data quality and governance

3. Define KPIs:
   - metric name
   - definition
   - formula
   - source system
   - refresh cadence
   - owner
   - target or benchmark

4. Design views:
   - headline KPI tiles
   - trend charts
   - funnel conversion
   - segment breakdown
   - exception list
   - action queue

5. Check dashboard quality:
   - each metric has a decision attached
   - no vanity metrics without context
   - definitions match lifecycle stages
   - filters are consistent
   - data freshness is visible

## Output

Create a dashboard spec:

| dashboard | audience | metric | definition | source | decision it supports |
|---|---|---|---|---|---|

Include recommended filters and views.
