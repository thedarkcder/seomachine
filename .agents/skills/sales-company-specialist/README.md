# sales-company-specialist

This Codex skill turns company research into SDR-ready intelligence.

It should usually run after `sales-research`.

## Expected input

- `COMPANY-RESEARCH.md`

## Output

- `COMPANY-INTELLIGENCE.md`

## Main job

Convert research into:

- fit score
- buying triggers
- likely buyers
- pain hypotheses
- outreach angles
- handoff notes for other sales skills
